This is an addon for the Vampirism mod in Minecraft 1.21.1, designed to enhance the role-playing experience for vampires, with a planned update for hunters in the future. 
You may notice that the source code in the root package is quite messy; this is due to my unfamiliarity with the tools being used (I might find time to clean it up later). 
Warning: Some parts of the code here were completed with the help of Copilot (mainly in areas I'm not familiar with, such as dialogue features), so I cannot guarantee that they are optimal solutions.
